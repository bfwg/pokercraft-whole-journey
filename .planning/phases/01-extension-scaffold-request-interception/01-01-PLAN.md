  <action>
Create `extension/` directory at project root.

**extension/manifest.json:**
- `manifest_version: 3`
- `name: "Pokercraft Date Unlocker"`
- `version: "0.1.0"`
- `description: "Unlocks full date range for Pokercraft session history"`
- `content_scripts` array with ONE entry:
  - `matches: ["https://my.pokercraft.com/*"]`
  - `js: ["content.js"]`
  - `world: "MAIN"` (critical — must run in page context to patch window.fetch)
  - `run_at: "document_start"` (critical — must patch before app loads)
- `permissions: []` (no special permissions needed for Phase 1)

**extension/content.js:**

1. Save original references FIRST before anything:
   ```js
   const originalFetch = window.fetch.bind(window);
   const originalXHROpen = XMLHttpRequest.prototype.open;
   const originalXHRSend = XMLHttpRequest.prototype.send;
   ```

2. Create helper: `log(...args)` that prefixes all output with `[Pokercraft Unlocker]`

3. Create helper: `isTargetRequest(url)` that returns true only if:
   - URL contains `/api/session/list/Holdem`
   - URL domain is `my.pokercraft.com` (use URL constructor)
   - URL has both `from` and `to` query parameters

4. Create helper: `parseDateRange(url)` that extracts `from` and `to` as Date objects and returns `{ from, to, days }` where `days` is the span in days.

5. Create helper: `isLargeRange(days)` returns `days > 25`.

6. Monkey-patch `window.fetch`:
   ```js
   window.fetch = async function(input, init) {
     const url = (input instanceof Request) ? input.url : String(input);
     if (isTargetRequest(url)) {
       const range = parseDateRange(url);
       log('Intercepted fetch:', url);
       log('Date range:', range.from.toISOString(), '→', range.to.toISOString(), `(${range.days} days)`);
       if (isLargeRange(range.days)) {
         log('Large range detected — will need chunking (Phase 2)');
         // For now, pass through even large ranges
       }
     }
     return originalFetch(input, init);
   };
   ```

7. Monkey-patch `XMLHttpRequest.prototype.open` and `.send`:
   - In `open`: capture method and URL on `this._pcUrl` and `this._pcMethod`
   - In `send`: if `isTargetRequest(this._pcUrl)`, log the same way as fetch
   - Always call original methods

8. Log on script load: `log('Content script loaded — fetch/XHR interception active')`

Do NOT add any DPoP logic — that's Plan 02.
Do NOT add chunking — that's Phase 2.
